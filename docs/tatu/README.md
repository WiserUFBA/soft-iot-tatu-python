# Documentação do TATU

Esta pasta contém documentação **específica do TATU (Tiny Application for Things Universal)** e da implementação Python mantida neste repositório.

O conteúdo aqui deve permanecer útil independentemente de um projeto, laboratório ou implantação específica.

## Ordem recomendada de leitura

1. [Visão geral do TATU](tatu-overview.md)
2. [Getting Started](getting-started.md)
3. [Protocolo e mensagens](protocol.md)

## Escopo

A documentação descreve a implementação atual do repositório e como utilizá-la sem pressupor a infraestrutura de um projeto específico.

Refatorações arquiteturais maiores não fazem parte desta documentação. Elas poderão ser discutidas depois a partir das limitações observadas no uso real.
