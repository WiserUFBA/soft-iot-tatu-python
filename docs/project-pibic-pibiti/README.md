## Relação com o TATU

O TATU é um componente da infraestrutura IoT utilizada pelo projeto, mas o projeto PIBIC/PIBITI possui escopo mais amplo, envolvendo broker MQTT, persistência de dados, AI Box, Edge AI, Aprendizado Federado, agentes inteligentes, experimentação e operação no IC.

Por isso, documentos específicos de implantação, arquitetura e gestão do projeto não devem ser tratados como documentação do protocolo TATU.
